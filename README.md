# 🛍️ Town Team Sales Analysis

## 📌 Project Overview
Analysis of Town Team clothing company sales data (2019–2021), 
covering revenue, product performance, and channel comparison 
(Online vs. On-Shop).

This project was completed as part of the **Data Analysis Diploma** 
at **Tech Mind Academy**.

---

## 🎯 Business Questions
- What are the total sales per year? Did we grow or decline?
- Which are the Top 5 best-selling items by revenue and quantity?
- How do Online vs. On-Shop sales compare per product?
- Which category performs best: Casual Wear or Semi Formal?

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Dashboard Design

---

## 📊 Project Steps

| Step | Description |
|------|-------------|
| 1️⃣ Raw Data | Original sales dataset |
| 2️⃣ Data Cleaning | Removed duplicates, applied 15% discount on Jeans-Denim |
| 3️⃣ Meta Data | Documented all column definitions |
| 4️⃣ Pivot Tables | Built KPIs and analysis tables |
| 5️⃣ Dashboard | Interactive visual dashboard |

---

## 📈 Key Insights
- **Total Sales:** E£957,435
- **Total Orders:** 1,036
- **Top Product:** Jeans - Levis (E£254,002)
- **On-Shop dominates:** E£892,500 vs Online E£64,935
